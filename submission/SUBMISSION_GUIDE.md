时间紧迫，建议按这个顺序：

### 1. 导出 Godot 项目为 HTML5（30 分钟）
打开 Godot → Project → Export → Add → Web → Export Project
- 输出文件夹：`submission/demo_html5/`
- 选 "Export with Debug" = 否
- 完成后会有 `index.html` + `index.js` + `index.wasm` + `index.pck`
- 把这个文件夹整个压缩为 zip：**飞盘高er夫-（队名）-20260529.zip**

> 第一次 export 可能要装 Godot 的 export templates（Editor → Manage Export Templates → Download）

### 2. 重做封面图（15-30 分钟）

**方案 A：用现有图改造**（最快）
