**情绪**: 沉浸，投入
**关键画面**: 完全是游戏画面，相机跟随飞盘穿过 3 个地形

## 风格关键词

- top-down 2D game screenshot
- flat shaded vector art (NOT 3D, NOT photorealistic)
- mobile/casual game UI aesthetic
- cyan trajectory line (signature game visual)
- clean readable HUD elements

## 负面 prompt

```
3D render, photorealistic, painterly, hand-drawn anime style,
isometric perspective, first-person view, dark moody scene,
ugly UI, blurred HUD, missing trajectory line, watermark
```

## 参考图

- **必看**：直接用游戏实机截图！按 F5 跑游戏，第 1/4/5 关各截 3 张
- 截图位置：H1 平投后落地中段、H4 水域上方、H5 硬地着陆瞬间

## 镜头说明

- **这是整支广告的核心卖点段**：观众必须明确看到"这是一个游戏"
- 3 个 keyframe 用视频生成串成连续镜头：
  - 0-1.7s 森林
  - 1.7-3.4s 湖泊
  - 3.4-5s 硬地 + 进筐前一刻
- 用游戏的青色轨迹线作为视觉锚点贯穿三个画面

## 重点

UI 元素一定要清楚出现，让观众知道"这是个游戏"而不是"用 CGI 模拟的飞盘"。
